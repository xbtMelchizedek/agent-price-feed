# Security

Report vulnerabilities privately through GitHub's **Report a vulnerability** button on this repository (Security tab, then Advisories). Please don't open a public issue.

In scope:
- Markup or script injection from source data into the page, RSS or JSON Feed.
- A way to make the build reset or rewrite history.
- The CLI or MCP server reading anything other than the feed it was pointed at.
- Events that report a price not present in the snapshot.

This project holds no keys, makes no payments and only reads public data.
