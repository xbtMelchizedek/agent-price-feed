agent-price-feed

What changed in inference prices since your agent last looked. Price drops, a new cheapest route, a new venue or model, or the first Flop testnet listing. Each event links the page or API it came from.

GitHub · JSON Feed · RSS · Built from justweight every 2 hours. 1 IU = 750k input + 250k output tokens.

Events

Use it from an agent

npx -y github:xbtMelchizedek/agent-price-feed events --kind price-drop,cheapest-change --model qwen3.8 --since 2026-11-24T00:00:00Z

Exits 0 when something matched and 1 when nothing did, so a cron job can alert on the exit code. As an MCP server (one tool, price_alerts):

{ "mcpServers": { "price-feed": { "command": "npx", "args": ["-y", "github:xbtMelchizedek/agent-price-feed", "mcp"] } } }
